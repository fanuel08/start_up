# Start Up 🚀

A Python starter project for quickly bootstrapping new development ideas. This repo contains foundational scripts and patterns I use as a jumping-off point for various Python projects.

## What's Inside?

A clean, minimal setup for Python development with:
- Basic project structure and conventions
- Essential dependencies pre-configured
- Simple entry point (`hello.py`) to build from
- Git best practices already in place

## Getting Started

### Prerequisites
- Python 3.6 or higher

### Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/fanuel08/start_up.git
   cd start_up
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the starter script**:
   ```bash
   python hello.py
   ``` 

You should see output confirming the setup is working.

## Project Structure

## How I Use This

This is my template for rapid prototyping. I:
1. Clone it as a base
2. Modify `hello.py` to fit the new project's needs
3. Add dependencies to `requirements.txt` as needed
4. Build from there
