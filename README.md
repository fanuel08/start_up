# Start Up

A simple Python startup project.

## Getting Started

### Prerequisites
- Python 3.6+

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/fanuel08/start_up.git
cd start_up
pip install -r requirements.txt
```

### Running

Execute the main script:

```bash
python hello.py
```
